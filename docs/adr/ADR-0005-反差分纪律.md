# ADR-0005:反差分纪律

## Context

D02-8 原始规格想关掉 console 上报的一切对象读取以杜绝探针 getter/Proxy 陷阱;2026-09-15 裸 CDP 实测通道图推翻前提:152 的 preview 序列化本就不调 accessor/不碰 Proxy 陷阱,真正开火的文本构建通道（V8ValueStringBuilder）在零 CDP 客户端的 stock 同样开火,属非差分通道 [实证: S006 通道矩阵,四端验证]。

## Decision

一切定制与 stock 行为对齐:无差分通道不改,改了反造新指纹;只关确证的 CDP 差分面（console 参数与未捕获异常的 preview 急切序列化,preview-off 保留 objectId 按需取）。文本通道保持原样。

## Consequences

- 好:页面可观测行为零变化,不主动暴露;对上游行为回归免疫
- 坏:与 stock 一致的开火通道（如 @@toStringTag 文本构建）不在治理范围;检测面军备只覆盖 CDP 差分层
