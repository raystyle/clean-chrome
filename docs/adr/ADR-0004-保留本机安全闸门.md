# ADR-0004:保留本机安全闸门

## Context

移除 CDP 摩擦时逐项审视了上游安全机制,三道闸门与本地自动化零冲突（S002 第四节,2026-09-11 裁定）;一旦全开开关又暴露外网,等于交出完整 CDP 控制权。

## Decision

明确保留:`RemoteDebuggingAllowed` 策略 gate（紧急关闭后门）、端口仅听 127.0.0.1（禁配 `--remote-debugging-address`）、Host header 校验（DNS rebinding 防护）;WS Origin gate 保持按需启动参数形态,不做默认放开。

## Consequences

- 好:开关全开也不暴露外机;策略通道留有紧急刹车
- 坏:网页内直连 CDP 的需求出现时要另立受控形态评估,不能简单放开 Origin
