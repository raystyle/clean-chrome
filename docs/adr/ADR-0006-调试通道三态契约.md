# ADR-0006:调试通道三态契约

## Context

客户端（browse-rs）需要 CDP 管道与端口两种通道形态;上游 pipe handler 原生无对话框路径（直接 AttachClient,与 auto-allow 互不相扰）,Windows 句柄契约走 `--remote-debugging-io-pipes`（AdoptPipes 收养）,断线关闸 CloseBrowserSoon,无效句柄自退不崩 [实证: S005,152 树源码实读 + 三态矩阵验证]。

## Decision

`CLEAN_CHROME_DEBUG` 环境变量三态 `port|pipe|both`,默认 `port`（即无参 9222 现行为）;值大小写不敏感,非法值回退 port;显式命令行开关永远压过变量;管道句柄由启动方传入,启动器范本 `tools\pipe-smoke.py`。

## Consequences

- 好:双击行为不变;客户端按需切管道免开端口;契约对三平台一致
- 坏:新增一个环境变量契约面,消费方（browse-rs）升级需对齐;断管关闸与 ASCIIZ/CBOR 协议语义必须长期保持
