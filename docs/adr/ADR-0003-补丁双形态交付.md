# ADR-0003:补丁双形态交付与等价纪律

## Context

补丁需要既能在三平台树上一键幂等重打,又能在升 tag 时以标准 git patch 形态核验。2026-09-11 前的 ps1 版在跨平台与编码上翻车（M001/M020）,同年起换 uv 运行的 Python 锚定脚本。

## Decision

两种交付形态并存且必须等价:`patches\apply-auto-allow.py`（uv 运行 PEP 723,锚定式,三模式 before/after/replace,默认用,幂等 ok/skip 计数自检）与 `patches\auto-allow-devtools-connections-<tag>.patch`（钉 tag 标准补丁）;改锚点或升 tag 必须先在 poc 参照树验证两形态字节等价再更新文件。

## Consequences

- 好:三平台零依赖重打;字节等价让两种用法永远同 semantics
- 坏:每改锚多一道等价验证工序;短路整段逻辑只能用替换式锚定,禁提前 return（-Wunreachable-code,M011）
