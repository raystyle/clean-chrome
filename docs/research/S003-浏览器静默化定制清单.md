## 二、实现定档【行】

- **NTP 路线**:不动 kChromeUINewTab* 常量(static_assert 锁定 + WebUI 深耦合),改 `prefs::kNewTabPageLocationOverride` 的注册默认值(profile_impl.cc)为 "about:blank";启动页、新标签、Ctrl+T 全部跟随,这是官方策略(NewTabPageLocation)的默认值化
- **搜索路线**:template_url_service.cc 注册默认 `kDefaultSearchProviderEnabled=false`;注意已持久化的旧 profile 会覆盖默认值,现役 profile 需重建或在设置中手动关
- **首跑**:out\Dev\initial_preferences(skip_first_run_ui / suppress 默认浏览器与气泡 / 不建快捷方式 / 不导入),Release 出产物后同放
- 其余提示走 infobar_utils.cc 集中替换(M011 纪律:replace 模式,禁提前 return;连变量定义一起替换,防 -Wunused-variable,2026-09-11 实证)

## 四、风险与边界【知】

- 默认搜索关闭后,地址栏输入非 URL 不再回退搜索(行为变化,正是需求);页面内 google.com 手动访问不受影响
- NTP override 只改默认值,用户仍可在设置改回;策略通道(NewTabPageLocation)仍可强制覆盖
- 本清单所有改动仍守 AGENTS 补丁边界纪律:一律锚定式、双形态等价、升 tag 重验
