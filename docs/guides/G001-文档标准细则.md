# G001：文档标准细则

> 本仓文档的命名、结构与事实标记标准（精简起步版，按需扩充）。

## 命名与编号

- 文件名即标题；不含空格、括号、冒号；research/diary 用 `-` 断句的博客式长标题
- 编号体系：`ADR-NNNN`（docs\adr,决策）`REQ-NNN`（docs\requirements,需求）`SNNN`（docs\research,研究）`RNNN`/`GNNN`（docs\guides,操作手册与工作流）`M0xx`（错误链行号,权威落位在 R001 十节与 G002 四节）;编号退役不复用;PNNNN 已于 2026-09-15 随 dev-evo 迁移退役（ADR-0007）

## 结构

- 标题干净（不带括号/口号/破折号），解释放标题下一行 `>` 引用
- 树形分层；h2 = 一节一事；命令进代码块；关键事实用表格

## 六态标记

事实性断言必标：`[实证: ...]` / `[推断: ...]` / `[经验: ...]` / `[记忆: ...]` / `[假设: ...]` / `[直觉: ...]`。关键结论必标；禁止把没验证写成已验证。五态为进入实证服务：`[假设]`/`[推断]` 写清验证动作、`[记忆]` 附复核点；悬空中转态收尾必处置（升实证、留 research 或注销）。

## 登记与门禁

- 新文档建成登记所在目录 README 索引；ADR/REQ 另须 frontmatter 契约（id/status/trace 等,拷各自 0000-template）
- 提交前必跑 `uv run tools\check.py .`（PE-01至12,退出码 0）;四类禁字由 md-guard 挡板在写入时拦截
