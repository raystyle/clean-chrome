# REQ-007:调试通道三态环境变量

关联:旧 PRD D02-6,2026-09-14 一轮澄清后立项;契约裁定 ADR-0006。

## Scenario

启动时自动初始调试通道形态,由环境变量控制 port/pipe/both,默认保持 9222 现行为;管道句柄由启动方传入。

## Criteria

- [x] `CLEAN_CHROME_DEBUG=port|pipe|both` 三态矩阵全绿（unset 至 9222 照旧;pipe 至管道 getTargets 往返且 9222 不听;both 至双通道）
- [x] 值大小写不敏感,非法值回退 port;显式开关永远压过变量
- [x] 断管关闸（CloseBrowserSoon）、无效句柄自退不崩（POSIX 走 abort 同为不留尸）
- [x] Windows 句柄契约 `--remote-debugging-io-pipes` 落地,启动器范本 tools\pipe-smoke.py
